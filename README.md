## About this repository

This repository documents two password-cracking exercises completed during the Week 3 practical module of the NetworkWalks Cybersecurity Internship. Both projects target the same encrypted PDF file (`My-Locked-PDF1.pdf`) and successfully recover its password using two different approaches:

1. **John the Ripper (via the Johnny GUI)** — a professional, locally-installed password-cracking suite
2. **NetworkWalks Hash Calculator + Password Cracker** — NetworkWalks Academy's own browser-based teaching tools that simulate the same dictionary-attack concept

Both methods recovered the same password (`password1`) for the same PDF hash and successfully captured the lab's flag: `nw{networkwalks_flag1_jtr_270521_1}`.
